# 怎么给空气吉他加内置歌曲（给人和 AI 看）

内置歌曲只改一个文件：`js/songs.js` 里的 `BUILTIN_SONGS` 数组。不需要改别的代码。

## 一首歌长这样

```js
{
  id: "songbie",              // 英文 id，唯一，不要以 p_ 开头（p_ 开头的会归到「和弦练习」）
  title: "送别（李叔同词，公有领域）",  // 下拉菜单里显示的名字
  style: "ballad",            // 曲风，见下表；决定速度、扫弦/分解、节奏型、鼓
  key: "C",                   // 这首歌写成哪个调（只用来给「自由弹」分配手指，可省略，会自动猜）
  bpm: 72,                    // 可选：覆盖曲风默认速度
  text: `[C]长亭外，[F]古道[C]边，芳草碧连[G]天。
[C]晚风拂柳[F]笛声[C]残，夕阳[G]山外[C]山。`,
},
```

- `text` 一行一句歌词，和弦用方括号写在**从这个字开始换和弦**的位置：`[C]长亭外，[F]古道[C]边`。
- 也可以用「和弦行在上、歌词行在下」的写法（和弦对齐到字的位置，中文一个字算两格）。
- 只练和弦、没有歌词：`text: "C G Am F"`。
- 段落名写成 `[主歌]`、`[副歌]` 这类非和弦内容，会原样显示在歌词里。
- 支持的和弦：C、Cm、C7、Cmaj7、Cm7、Csus2、Csus4、Cdim、Caug（任意根音，# 或 b 都行）；`G/B` 会按 G 弹；`Cadd9`、`C6`、`C9` 按 C 弹。

## 曲风（style）可选值

| style | 名字 | 速度 | 弹法 | 节奏型 | 鼓 |
|---|---|---|---|---|---|
| ballad | 抒情慢歌 | 72 | 分解 | 慢歌分解 R321 2323 | 抒情慢歌（边击） |
| folk | 民谣弹唱 | 88 | 扫弦 | 低音 + 民谣扫弦 | 民谣 |
| pop | 流行 | 100 | 扫弦 | 切音 | 流行律动 |
| rock | 摇滚 | 124 | 扫弦 | 摇滚八分下扫 | 摇滚 |
| kids | 儿歌 | 96 | 扫弦 | 四分下扫 | 轻柔镲帽 |
| waltz | 三拍子（华尔兹） | 100 | 扫弦 | 华尔兹 3/4 | 自动用华尔兹鼓 |
| waltz_fingers | 三拍子指弹 | 80 | 分解 | 3/4 分解 | 不开鼓 |
| fingerstyle | 安静指弹 | 76 | 分解 | Travis 交替低音 | 不开鼓 |
| blues | 布鲁斯 | 90 | 扫弦 | 布鲁斯摇摆 | 布鲁斯摇摆 |
| reggae | 雷鬼 | 92 | 扫弦 | 雷鬼/斯卡反拍 | 雷鬼 One Drop |

想要新曲风：在 `js/songs.js` 的 `STYLES` 里加一项；节奏型 id 必须是 `js/patterns.js` 里已有的（`STRUM_PATTERNS` / `ARP_PATTERNS` / `DRUM_PATTERNS`）。

## 版权（重要）

- **只能内置公有领域或自己有权使用的歌词。** 中国大陆一般是作者去世满 50 年；传统民歌、老儿歌、作者 1975 年前去世的作品通常可以。流行歌（周杰伦、陈奕迅、五月天等）的歌词**不能内置**，让用户自己用「导入」粘贴或截图识别，只保存在用户浏览器里。
- 和弦走向本身不受版权保护，可以做成「和弦练习」（`id` 以 `p_` 开头、只写和弦）。

## 加完怎么检查

```bash
node tests/run.mjs
```

测试会检查：每首内置歌都能解析出至少 3 个和弦、`style` 是有效曲风。再本地打开 `python3 -m http.server 8765`，在「设置 → 歌曲与和弦」里选这首歌，切到「跟谱弹唱」看歌词和和弦位置对不对。
