# 🎸 Vibe Air Guitar

空气吉他 — 基于浏览器的手势识别弹奏应用

用单手手势、触屏或键盘演奏，在浏览器里练习和弦、录下一段音乐。纯前端，无需登录或后端。

## 2026 年 10 月 · V34 单手演奏与性能精简

- 首屏移除占高度的标题区，缩小和弦按钮与演奏舞台；桌面和手机的主要演奏控件更容易留在首屏。
- 音色选择收敛到 3 种真实吉他采样：尼龙、木吉他、清音电吉他。旧配置里的其他音色会安全切回尼龙吉他。
- 采样从约 184 MB 的长 WAV / 多力度文件，改为约 1.7 MB 的短 MP3；默认只预载当前和弦所需的少量音，其余按需加载。历史文件保存在 `backup/pre-performance-20261007` 分支。
- 采样没到齐时立即发声，已加载的最近音高可直接用于当前音；减少首弹时的合成计算与音量表的逐帧开销。
- 平衡手势模式改用轻量模型以减少推理耗时。真实摄像头延迟仍取决于设备、光线和浏览器。

默认摄像头模式现在只跟踪一只手：伸出 1–5 指选和弦，保持手势上下挥动同一只手即可扫弦，无需开启伴奏或使用第二只手。原双手模式和自动伴奏仍能在设置中切换。手机轻量模式提高到 24fps，手部绘图不再逐帧重设画布尺寸。

调研的 6 个开源实现与本次性能取舍见 [性能优化调研](docs/performance-research-2026-10.md)。

## 2026 年 10 月 · V32

- 六根触控琴弦：单弦拨奏、上下滑动扫弦，保留真实吉他和弦按法与闷弦。
- 双手演奏：镜像画面的一侧伸 1–5 指选和弦，另一侧上下挥动扫弦，力度影响音量；左右手角色可交换。也保留单手选和弦与自动伴奏。
- 手势旋转不再直接按画面 Y 轴判断；加入稳定窗口、挥动行程阈值、冷却时间与丢手恢复保护。
- 和弦跟练、每小节切换和弦的循环播放、40–200 BPM、点拍测速、独立节拍器。
- 应用音频录制与下载（格式由浏览器决定），不录摄像头或麦克风；每段最长 5 分钟，当前页面最多保留 5 段。节拍器不进入录音。
- 音量与输出电平、配置自动保存、JSON 导入导出（校验版本和数值范围）。录音和上传音频不包含在配置里。
- 桌面双栏工作台，手机大琴弦与抽屉控制台；亮/暗主题、新手说明、键盘快捷键与全屏。
- 摄像头依赖按需加载；音色加载期间使用合成拨弦，不阻塞演奏。V33 后三种真实吉他改为小体积本地采样。

研究依据、取舍和验收记录见 [10 月升级说明](docs/upgrade-research-2026-10.md)。

## ✨ 功能

- 🖐️ **手势识别** — MediaPipe Hands 识别 1-5 号手势，映射到不同和弦
- 🎵 **三种吉他音色** — 尼龙吉他、University of Iowa 真实木吉他采样、清音电吉他；其他实验音色已从菜单移除
- 🥁 **鼓节奏** — 内置 20 种鼓节奏型
- 🎸 **吉他节奏** — 20 种扫弦/分解节奏型
- 🎶 **和弦谱编辑** — 支持自定义和弦走向，内置多种预设模板
- 🎛️ **鼓组伴奏** — 独立启停与节奏选择
- 🌗 **亮/暗主题** — 一键切换
- 🎯 **调性切换** — 12 调可选，支持 Capo
- 📱 **三档性能模式** — 手机默认轻量省电，桌面可选平衡或演出低延迟
- ✨ **Studio 级界面** — 桌面工作台与手机抽屉式控制，核心演奏信息始终可见

## ⚡ 性能模式

| 模式 | 适用场景 | 识别策略 |
| --- | --- | --- |
| 轻量版 | 手机、长时间练习 | 480×360 / 最多 24fps / 关闭面部特效，降低发热 |
| 平衡版 | 日常使用（默认） | 640×480 / 最多 30fps / 轻量手部模型 |
| 完全版 | 短时演出、性能较强的设备 | 720×540 / 30fps，可开启舞台特效 |

## 🚀 使用

1. 克隆仓库
   ```bash
   git clone https://github.com/91vrvd/vibe-air-guitar.git
   cd vibe-air-guitar
   ```

2. 启动本地服务器（需要摄像头权限，必须用 HTTP 服务）
   ```bash
   python3 -m http.server 8765
   ```

3. 打开浏览器访问 `http://localhost:8765`

4. 选择下方和弦，点按或划过琴弦。键盘 `1–5` 选和弦，`↑ / ↓` 扫弦，空格切换伴奏（编辑输入框和操作按钮时保留原生按键行为）。
5. 可选：开启摄像头，只让一只手入镜。伸出 1–5 指选和弦，保持指形上下挥动这只手扫弦；握拳静音。摄像头画面只在本机推理，不上传。
6. 录音结束后在「演奏 → 我的录音」试听、下载。关闭网页前务必保存。

## 测试

```bash
node --test _tests/studio-core.test.cjs
```

本地服务打开 `/_tests/browser.html`，点击“运行验收”验证真实 Web Audio 输出、和弦调度、录音解码、跟练与配置校验；“测试手势模型”仅使用空白画面及模拟权限失败，不访问摄像头。`_tests` 默认不由 GitHub Pages / Jekyll 发布。

测试手势算法和空白帧推理不能替代真人摄像头测试；低光、遮挡、设备性能以及 iOS 后台/静音行为仍需在实际设备上验收。

## 📁 项目结构

```
├── index.html          # 主页面
├── app.js              # 核心逻辑（手势识别、音频引擎、和弦映射）

    ├── chord-strums/   # 和弦扫弦采样
    └── optimized/      # 三种吉他的短采样（尼龙、木吉他、电吉他）
```

## 🛠️ 技术栈

- **MediaPipe Hands** — 手部关键点检测
- **MediaPipe Face Detection** — 面部检测（辅助）
- **Web Audio API** — 音频合成与播放
- **Canvas API** — 手部骨架绘制
